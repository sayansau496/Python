## 🔢 1. NumPy

NumPy is a Python library for numerical computing and efficient operations on multidimensional arrays.

**Key learning areas:**

* Array creation and manipulation
* Array indexing and slicing
* Mathematical and arithmetic operations
* Statistical calculations
* Minimum, maximum, mean, and standard deviation
* Numerical data processing

## 🐼 2. Pandas

Pandas is a powerful Python library for working with structured datasets and performing data analysis.

**Key learning areas:**

* Series and DataFrames
* Reading and analyzing datasets
* Data selection and filtering
* Sorting and organizing data
* Data cleaning and preprocessing
* Statistical summaries
* Grouping and aggregation

## 📊 3. Matplotlib

Matplotlib is a Python visualization library used to represent data through charts and graphs.

**Key learning areas:**

* Line charts
* Bar charts
* Pie charts
* Histograms
* Scatter plots
* Chart titles, labels, and legends
* Visual exploration of datasets

## ⚙️ Installation and Setup

### Step 1: Clone the repository

```bash
git clone https://github.com/sayansau496/Python-Data-Analysis-NumPy-Pandas-Matplotlib.git
```

### Step 2: Navigate to the project folder

```bash
cd Python-Data-Analysis-NumPy-Pandas-Matplotlib
```

### Step 3: Install the required libraries

```bash
pip install numpy pandas matplotlib jupyter openpyxl
```

### Step 4: Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the required `.ipynb` file and execute the cells to explore the examples.
